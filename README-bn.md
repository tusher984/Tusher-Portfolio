# আপনার ওয়েবসাইট — বাংলা নির্দেশিকা

লাইভ সাইট: **https://tusher984.github.io/Tusher-Portfolio/**
ড্যাশবোর্ড: **https://tusher984.github.io/Tusher-Portfolio/admin/**

সাইটের সব কিছুই — ছবি, ভিডিও, রিপোর্টের তালিকা, আপনার পরিচিতি, কাজের অভিজ্ঞতা,
দক্ষতা, শিক্ষা, যোগাযোগের তথ্য আর প্রতিটি শিরোনাম — ড্যাশবোর্ড থেকে বদলানো যায়।
সাইটের লেখা বদলাতে কোড ছোঁয়ার দরকার নেই।

*এটি [README.md](README.md)-এর বাংলা রূপ, কাজ করার সময় হাতের কাছে রাখার জন্য।
দুটির তথ্য এক; ইংরেজিটিই মূল ফাইল।*

## ড্যাশবোর্ডে ঢোকার তিনটি উপায়

### উপায় ১ — আজই শুরু করুন, কোনো সেটআপ ছাড়াই (৫ মিনিট)

এটি একই ড্যাশবোর্ড, শুধু আপনার নিজের কম্পিউটারে চলবে। কোনো লগইন লাগে না, কোনো
অ্যাকাউন্ট লাগে না, অপেক্ষাও করতে হয় না। Terminal খুলে সাইটের ফোল্ডারের ভেতর থেকে
চালান:

```bash
cd ~/Documents/GitHub/Tusher-Portfolio
npx decap-server
```

এটি চলতে দিন, বন্ধ করবেন না। এখন **দ্বিতীয় একটি** Terminal উইন্ডো খুলে চালান:

```bash
cd ~/Documents/GitHub/Tusher-Portfolio
python3 -m http.server 8000
```

ব্রাউজারে **http://localhost:8000/admin/** খুলুন, তারপর **Work with Local Repo**
বোতামে ক্লিক করুন। সবই কাজ করবে — ছবি টেনে এনে ছেড়ে দেওয়া, লেখা বদলানো, publish
করা। পরিবর্তনগুলো সরাসরি আপনার কম্পিউটারের ফাইলে জমা হবে।

কাজ পছন্দ হলে ইন্টারনেটে পাঠিয়ে দিন:

```bash
git add -A && git commit -m "Update site" && git push
```

প্রায় এক মিনিট পরে লাইভ সাইটে পরিবর্তন দেখা যাবে।

### উপায় ২ — যেকোনো জায়গা থেকে লগইন (একবারের সেটআপ, ১০ মিনিট)

একবার সেট হয়ে গেলে ফোন থেকে, ধার করা ল্যাপটপ থেকে, যেকোনো জায়গা থেকে শুধু
`/admin/` খুলে একটি বোতামে ক্লিক করেই সাইট সম্পাদনা করতে পারবেন।

এই ফোল্ডারের **`admin/login-helper.js`** ফাইলটি খুলুন — ধাপগুলো ফাইলের একেবারে
ওপরেই লেখা আছে। সংক্ষেপে: GitHub-এ একটি OAuth app তৈরি করা, কোডটি একটি ফ্রি
Cloudflare Worker-এ paste করা, তারপর সেই worker-এর ঠিকানা `admin/config.yml`
ফাইলের `base_url:` লাইনে বসানো।

একটা কথা পরিষ্কার করে বলা দরকার: সাইটটি বানানোর সময় আমার ইন্টারনেট সংযোগ ছিল না,
তাই Cloudflare আর GitHub-এর পর্দাগুলো আমি নিজে ঘুরে দেখতে পারিনি। কোড ঠিক আছে
এবং ধাপগুলো যত্ন করে লেখা, কিন্তু ওই ওয়েবসাইটগুলোর বোতামের নাম এর মধ্যে বদলে
থাকতে পারে। লগইনের পপআপ খুলে সঙ্গে সঙ্গে বন্ধ হয়ে গেলে কারণ প্রায় সবসময় একটাই:
GitHub app-এর **Authorization callback URL** আর worker-এর ঠিকানা হুবহু মেলেনি —
শেষে `/callback` আছে কি না দেখুন।

### উপায় ৩ — ড্যাশবোর্ড ছাড়াই

চাইলে সরাসরি github.com-এ গিয়েও বদলাতে পারেন। রিপোজিটরিতে ঢুকে `content/`
ফোল্ডার, তারপর যেকোনো `.json` ফাইল, পেন্সিল আইকন, লেখা বদলে **Commit**। ছবি যোগ
করতে `uploads` ফোল্ডার খুলে **Add file → Upload files**। ড্যাশবোর্ডের মতো
আরামদায়ক নয়, কিন্তু কিছুই সেটআপ করতে হয় না এবং যেকোনো ব্রাউজার থেকে চলে।

## ছবি আপলোড করা

ড্যাশবোর্ডে **Photographs** খুলুন, Photographs তালিকা পর্যন্ত নামুন,
**Add Photograph**-এ ক্লিক করুন, তারপর ছবিটি Photograph ঘরের ভেতরে টেনে এনে ছেড়ে
দিন। শিরোনাম দিন, আর ক্যাপশনে কী ঘটছে তা লিখুন — এই ক্যাপশনটিই দৃষ্টিপ্রতিবন্ধী
পাঠকের স্ক্রিন রিডার পড়ে শোনায়, তাই যত্ন করে লেখা ভালো।

**Category** ঘরে ওই পর্দার ওপরে দেওয়া ফিল্টারগুলোর একটি হুবহু একই বানানে লিখুন
(`Environment`, `Portraits`, `Urban life`, `Reportage`) — তাহলে ছবিটি সেই
ফিল্টারের নিচে দেখা যাবে। নতুন ক্যাটাগরি লাগলে আগে ওই তালিকায় যোগ করে নিন।

তালিকার **প্রথম চারটি ছবি** হোমপেজেও দেখা যায়, তাই সবচেয়ে ভালো কাজটি ওপরে টেনে
আনুন।

একটি ব্যবহারিক পরামর্শ: আপলোডের আগে বড় ফাইল ছোট করে নিন। ক্যামেরা থেকে সরাসরি
নেওয়া JPEG সাধারণত 8–15MB হয়, আর এমন ছবিভরা গ্যালারি বাংলাদেশে মোবাইল ডেটায়
খুলতে অনেক সময় নেয়। লম্বা দিকে প্রায় 2000px আর প্রতিটি 500KB-র নিচে রাখলে পর্দায়
দেখতে একই লাগে, কিন্তু খোলে অনেক দ্রুত। macOS-এর Preview দিয়েই করা যায়:
Tools → Adjust Size।

## ভিডিও যোগ করা

**Videos** খুলে **Add Video**-তে ক্লিক করুন। ভিডিওটি তিন উপায়ে দিতে পারেন, আর
সাইট এই ক্রমে যেটি আগে পায় সেটিই ব্যবহার করে:

**YouTube** — পুরো ঠিকানা নয়, শুধু ID বসান। `youtube.com/watch?v=dQw4w9WgXcQ`-এ
ID হলো `dQw4w9WgXcQ`। থাম্বনেইল নিজে থেকেই চলে আসে, আলাদা কভার ছবি দিতে হয় না।

**Vimeo** — ঠিকানার শেষের সংখ্যাটি বসান, যেমন `76979871`।

**নিজে ক্লিপ আপলোড** — *Or upload a clip* ঘরে MP4 ফাইলটি দিন, আর সঙ্গে একটি কভার
ছবিও দিন, কারণ এখানে থাম্বনেইল টেনে আনার কোনো জায়গা নেই।

আপলোড করা ক্লিপ প্রায় 25MB-র নিচে রাখুন। GitHub ভিডিও রাখার জায়গা নয় — এটি
একটিমাত্র ফাইল 100MB-র বেশি হলে নেয় না, আর YouTube-এর মতো ধীর সংযোগ বুঝে
কোয়ালিটি কমায়ও না। ৩০ সেকেন্ডের ক্লিপ ঠিক আছে। দশ মিনিটের ডকুমেন্টারি YouTube-এ
রেখে ID-টা এখানে বসানোই ভালো।

**About & beats** — আপনার পরিচিতির অনুচ্ছেদ, পোর্ট্রেট ছবি আর "What I cover"-এর

বুলেট পয়েন্ট। *This is my current job* টিক দিলে টাইমলাইনে ওই এন্ট্রিতে আলো-জ্বলা
বিন্দুটি বসে।

**Skills & tools**, **Education & fellowships** আর **Contact details** একইভাবে
কাজ করে — তালিকায় যোগ করুন, টেনে ক্রম বদলান।

**Headings & wording** — বাকি সব: ওপরের প্রধান শিরোনাম, শুরুর অনুচ্ছেদ, বোতামের
লেখা, প্রতিটি সেকশনের শিরোনাম আর আপনার সোশ্যাল লিংক।

যেকোনো অনুচ্ছেদের ঘরে লিংক বসাতে লিখুন `[Netra News](https://netra.news/)`, আর
কোনো শব্দ মোটা করতে দুই পাশে `**দুটি তারা**` দিন। ইচ্ছে করেই শুধু এই দুটি সুবিধা
রাখা হয়েছে — এর ফলে আপনি যা-ই টাইপ করুন, সাইট ভেঙে যাবে না।

করেছি।

**নয়টি ছবি।** গ্যালারিতে এখন ধূসর প্লেসহোল্ডার বসানো আছে।

**তিনটি ভিডিও ID।** "Dhaka's Dying Rivers" সহ।

## কয়েকটি দরকারি কথা

**পাতা খালি দেখালে।** `index.html`-এ দুবার ক্লিক করে খুললে "content not loading"
জাতীয় বার্তা আসে। এটি স্বাভাবিক, কোনো ত্রুটি নয় — হার্ড ড্রাইভ থেকে খোলা পাতাকে
ব্রাউজার অন্য ফাইল পড়তে দেয় না। ফোল্ডারের ভেতরে `python3 -m http.server 8000`
চালিয়ে `localhost:8000` খুলুন, বা সোজা লাইভ সাইটটাই দেখুন।

**রং আর ফন্ট।** সবই `assets/css/style.css` ফাইলের একেবারে ওপরের একটি ব্লকে আছে।
`--accent` বদলালে গোটা সাইটের রং বদলে যায়। এখনকার টিল রংটি আপনার ছাপানো CV থেকে
নেওয়া, যাতে দুটি মিলে যায়।

**`.nojekyll` ফাইলটি।** ব্রাউজার দিয়ে ফোল্ডার আপলোড করার সময় এই ফাইলটি চুপচাপ বাদ
পড়ে যায় — ডট দিয়ে শুরু হওয়া ফাইল ব্রাউজার এড়িয়ে যায়। আমি ফিরিয়ে দিয়েছি।
ভবিষ্যতে আবার ওভাবে আপলোড করলে দেখে নেবেন এটি আছে কি না, নয়তো `git push`
ব্যবহার করবেন।

**ইচ্ছে করে নেওয়া কিছু সিদ্ধান্ত।** আপনার সম্পাদকের ই-মেইল CV-তে ছিল, কিন্তু
সাইটের কোথাও সেটি রাখা হয়নি; বদলে references-এর জায়গায় "available on request"
লেখা আছে — এটিই প্রচলিত রীতি এবং এতে ঠিকানাটি scraper-দের হাত থেকে বাঁচে।
নিশ্চিত লিংক নেই যেসব রিপোর্টের, সেগুলো Netra News-এর হোমপেজে না পাঠিয়ে
"Link coming" লিখে রাখা হয়েছে, কারণ ভুল জায়গায় নিয়ে যাওয়া লিংকের চেয়ে লিংক না
থাকা ভালো। আর রিপোর্টের তালিকা তারিখ অনুযায়ী সাজানো নয় — আপনি টেনে যে ক্রমে
রাখবেন সেই ক্রমেই দেখাবে, যাতে তারিখহীন রিপোর্টটি নিচে নেমে গিয়ে সবচেয়ে পুরোনো
কাজ বলে মনে না হয়।

## যা যাচাই করা হয়নি

সাইটের গঠন ভালোভাবে পরীক্ষা করা হয়েছে — ফাইলগুলো ঠিকভাবে পড়া যায়, কোনো লিংক
অস্তিত্বহীন জায়গায় যায় না, ড্যাশবোর্ডের প্রতিটি ঘর আসল ফাইলের সঙ্গে মেলে। কিন্তু
আমার হাতে কোনো ব্রাউজার ছিল না, তাই **তৈরি পাতাটি আসলে কেউ চোখে দেখেনি**। খুলে
দেখে ডিজাইনটা আপনি নিজেই বিচার করুন।
