# আপনার ওয়েবসাইট — বাংলা নির্দেশিকা

লাইভ সাইট: **https://tusher984.github.io/Tusher-Portfolio/**
ড্যাশবোর্ড: **https://tusher984.github.io/Tusher-Portfolio/admin/**

সাইটের প্রতিটি লেখা, ছবি আর ভিডিও ওই ড্যাশবোর্ড থেকে বদলানো যায় — ফোন থেকেও।
কোড ছোঁয়ার দরকার নেই, নিজের কম্পিউটারে কোনো সার্ভার চালানোরও দরকার নেই।

*এটি ইংরেজি নির্দেশিকা `admin/guide.html`-এর বাংলা রূপ (ড্যাশবোর্ডের নিচে
"How this works" লিংক)। দুটির তথ্য এক।*

---

## ড্যাশবোর্ডে ঢোকা

দুটি ধাপ, আর দুটির কাজ আলাদা।

### ধাপ ১ — Admin আর পাসওয়ার্ড

এটি এই পাতার দরজার তালা। অন্য কেউ যেন সম্পাদকে ঢুকতে না পারে, সেটুকুই এর কাজ —
এই ধাপ পার না হওয়া পর্যন্ত ড্যাশবোর্ডটি ডাউনলোডই হয় না। ব্রাউজার বন্ধ করলে
আবার চাইবে।

নাম আর পাসওয়ার্ড আপনার জানা। বদলাতে চাইলে `admin/index.html` ফাইলের ভেতরে
`HASH` লেখা লাইনটির ঠিক ওপরে কীভাবে করবেন লেখা আছে — পাসওয়ার্ডটি ফাইলে হুবহু
রাখা হয় না, তার SHA-256 ছাপ রাখা হয়, যাতে পাবলিক রিপোজিটরিতে সেটি খোলা পড়ে না
থাকে।

### ধাপ ২ — GitHub টোকেন

কোনো পরিবর্তন সেভ করা মানে আপনার GitHub রিপোজিটরিতে লেখা, তাই GitHub-এর অনুমতি
ছাড়া কিছুই প্রকাশ হয় না। টোকেন হলো GitHub-এ নিজের বানানো একটি লম্বা পাসওয়ার্ড।
এতে কোথাও কিছু বসাতে হয় না, আজই কাজ করে, আর ফোন থেকেও চলে।

1. GitHub-এ খুলুন **Settings → Developer settings → Personal access tokens →
   Fine-grained tokens**, চাপুন **Generate new token**।
2. **Repository access**-এ বাছুন *Only select repositories*, তারপর
   **Tusher-Portfolio**।
3. **Repository permissions**-এ **Contents** করুন *Read and write*। আর কিছুই
   লাগবে না।
4. মেয়াদ ঠিক করে টোকেনটি তৈরি করুন আর কপি করুন — GitHub এটি একবারই দেখায়।
5. ড্যাশবোর্ডে paste করে **Open the editor** চাপুন।

কাজ চালাতে অক্ষম টোকেন সঙ্গে সঙ্গেই ফিরিয়ে দেওয়া হয়, কারণ জানিয়ে: মেয়াদ শেষ,
বা এই রিপোজিটরি দেখতে পায় না, বা পড়তে পারে কিন্তু লিখতে পারে না। ঠিক টোকেন
পাওয়ার আগে কিছুই সেভ হয় না।
