# আপনার ওয়েবসাইট — বাংলা নির্দেশিকা

লাইভ সাইট: **https://tusher984.github.io/Tusher-Portfolio/**
ড্যাশবোর্ড: **https://tusher984.github.io/Tusher-Portfolio/admin/**

সাইটের প্রতিটি লেখা, ছবি আর ভিডিও ওই ড্যাশবোর্ড থেকে বদলানো যায়। এটি নিজের
কম্পিউটারে চলে এবং পরিবর্তন সরাসরি এই প্রজেক্টের ফাইলে জমা হয়।

*এটি ইংরেজি নির্দেশিকা `admin/guide.html`-এর বাংলা রূপ (ড্যাশবোর্ডের নিচে
"How this works" লিংক)। দুটির তথ্য এক।*

---

## লোকাল ড্যাশবোর্ড খোলা

এই পদ্ধতিতে GitHub token, Netlify, বা online login কিছুই লাগবে না। দুটি Terminal
window লাগবে।

### ১ — প্রথম Terminal: CMS চালু করুন

```bash
cd ~/Documents/GitHub/Tusher-Portfolio
npx decap-server
```

এই window বন্ধ করবেন না।

### ২ — দ্বিতীয় Terminal: সাইট চালু করুন

```bash
cd ~/Documents/GitHub/Tusher-Portfolio
python3 -m http.server 8000
```

এই window-টিও খোলা রাখুন।

### ৩ — Editor খুলুন

ব্রাউজারে খুলুন:

```text
http://localhost:8000/admin/
```

তারপর **Work with Local Repo** চাপুন। এখন লেখা, ছবি, ভিডিও—সবকিছু বদলাতে পারবেন।
পরিবর্তনগুলো সঙ্গে সঙ্গে নিজের কম্পিউটারের ফাইলে জমা হবে, কিন্তু তখনও অনলাইনে যাবে না।

## সেভ আর প্রকাশ

1. সেকশন খুলে যা বদলাতে চান বদলান এবং **Save** চাপুন। ফাইলটি আপনার কম্পিউটারে সেভ হবে।
2. কাজ শেষে Terminal-এ চালান:

   ```bash
   git add -A
   git commit -m "Update portfolio"
   git push
   ```

3. প্রায় এক মিনিট অপেক্ষা করে লাইভ সাইট রিফ্রেশ করুন। GitHub Pages নতুন সংস্করণ প্রকাশ করবে।

## ছবি যোগ করা

**৪ · Photography** খুলে **Add Photographs** চাপুন, ছবিটি আপলোড করুন, আর ক্যাপশন
লিখুন। হোমপেজের সারিতে আর গ্যালারি পাতায় একসঙ্গেই দেখা যাবে।

**Title** ঘরটি স্ক্রিন রিডারও পড়ে শোনায়, তাই ফ্রেমে কী আছে সেটিই লিখুন।

**Category** ঘরটি দিয়েই গ্যালারি পাতার ফিল্টার বোতামগুলো ছবি সাজায়, তাই বানান
হুবহু মিলতে হবে — `Environment` আর `environment` দুটি আলাদা জিনিস। এখনকার
বোতামগুলো: `Environment`, `Portraits`, `Urban life`, `Reportage`। যে বোতামের
পিছনে একটিও ছবি নেই সেটি লুকিয়ে থাকে, আর ডানদিকের প্রিভিউ সেটি জানিয়ে দেয়।
Category খালি রাখলে ছবিটি গ্যালারিতে থাকে, শুধু কোনো ফিল্টারে ধরা পড়ে না।

আপলোডের আগে বড় ফাইল ছোট করে নিন। ক্যামেরা থেকে সরাসরি নেওয়া JPEG সাধারণত ৮–১৫MB
হয়, আর এমন ছবিভরা গ্যালারি বাংলাদেশে মোবাইল ডেটায় খুলতে অনেক সময় নেয়। লম্বা দিকে
প্রায় 2000px আর প্রতিটি ৫০০KB-র নিচে রাখলে পর্দায় দেখতে একই লাগে, কিন্তু খোলে
অনেক দ্রুত। macOS-এর Preview দিয়েই করা যায়: Tools → Adjust Size।

দেখালে বুঝবেন লিংকটি পড়া যায়নি।

## কয়েকটি দরকারি কথা

**`index.html` দুবার ক্লিক করে খুললে পাতা খালি দেখাবে।** এটি ত্রুটি নয় — হার্ড
ড্রাইভ থেকে খোলা পাতাকে ব্রাউজার পাশের ফাইলগুলো পড়তে দেয় না। লাইভ সাইটটাই দেখুন।

**রং আর ফন্ট।** সবই `assets/css/style.css` ফাইলের একেবারে ওপরের একটি ব্লকে আছে।
`--accent` বদলালে গোটা সাইটের রং বদলে যায়। এখনকার টিল রংটি আপনার ছাপানো CV থেকে
নেওয়া, যাতে দুটি মিলে যায়।

**`.nojekyll` ফাইলটি।** ব্রাউজার দিয়ে ফোল্ডার আপলোড করার সময় ডট দিয়ে শুরু হওয়া
ফাইল চুপচাপ বাদ পড়ে যায়। ফাইলটি এখন জায়গামতোই আছে; ভবিষ্যতে ওভাবে আপলোড করলে দেখে
নেবেন, নয়তো `git push` ব্যবহার করবেন।

**ড্যাশবোর্ড ছাড়াই বদলানো।** চাইলে সরাসরি github.com-এ গিয়েও পারেন:
রিপোজিটরিতে `content/` ফোল্ডার → যেকোনো `.json` ফাইল → পেন্সিল আইকন → লেখা বদলে
**Commit**। ছবির জন্য `uploads` ফোল্ডারে **Add file → Upload files**। আরামদায়ক
নয়, কিন্তু কিছুই সেটআপ করতে হয় না।

## যা পরীক্ষা করা হয়েছে

ড্যাশবোর্ডের প্রতিটি ঘর আসল ফাইলের সঙ্গে মেলে কি না, ছবি-ভিডিও পাতা, গ্যালারির
ফিল্টার ও lightbox, ফোনের চওড়ায় layout, এবং মেনুর লিংকগুলো ঠিক সেকশনে নামে কি না
পরীক্ষা করা হয়েছে। লোকাল editor চালাতে শুধু ওপরের দুটি Terminal command লাগবে।
