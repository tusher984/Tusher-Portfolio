Portfolio dashboard

নিজের কম্পিউটার থেকে, চাইলে ব্রাউজার থেকেও।

দুটি পথ, একই editor। Local mode এখনই তৈরি — দুটি Terminal command, কোনো account বা password ছাড়াই, আর সব পরিবর্তন সরাসরি আপনার project folder-এ সেভ হয়। Online mode একবার সেট করে নিলে live /admin/ ঠিকানাতেই “Login with GitHub” আসে; তখন আর এই কম্পিউটারটিরই দরকার থাকে না।

Local mode · শুরু করার নিয়ম

দুটি Terminal, চারটি ছোট ধাপ।

প্রথমবার npx Decap CMS download করতে ইন্টারনেট লাগতে পারে। পরেরবার সাধারণত শুধু command দুটো চালালেই হবে।

  1. 1

    Portfolio folder-এ Terminal খুলুন

    নিচের সব command এই folder-এর ভিতর থেকেই চালাতে হবে। Terminal প্রথমে home folder-এ খোলে, তাই folder-টিতে যেতে হবে। ⌘ Space চেপে Terminal লিখে Return দিন, তারপর নিচের লাইনটি paste করে আবার Return দিন।

    cd ~/Documents/GitHub/Tusher-Portfolio

    অথবা Finder-এ Tusher-Portfolio folder-টিতে Control-click করে Services → New Terminal at Folder বেছে নিন — window সোজা folder-এর ভিতরেই খোলে।

    ঠিক জায়গায় আছেন কি না দেখতে ls চালান। index.html, admin আর content দেখা গেলে ঠিক আছে।

  2. 2

    Local CMS চালু করুন

    এই লাইনটিও folder-এ যাওয়া আর CMS চালু করা — দুটোই করে, তাই Terminal কোথায় খুলেছে তা নিয়ে ভাবতে হবে না। এই window খোলা রাখুন; এটিই আপনার ফাইলগুলো edit করার অনুমতি দেয়।

    cd ~/Documents/GitHub/Tusher-Portfolio && npx decap-server
  3. 3

    আরেকটি Terminal খুলুন

    প্রথম window বন্ধ না করে ⌘ N চেপে নতুন window খুলুন। নতুন window আবার home folder-এ শুরু হয়, তাই নিচের একটি লাইনেই folder-এ যাওয়া আর server চালু করা — দুটোই আছে। paste করে Return দিন। এই window-টিও খোলা রাখবেন।

    cd ~/Documents/GitHub/Tusher-Portfolio && python3 -m http.server 8000
  4. 4

    Local editor খুলুন

    নিচের address browser-এ খুলুন, তারপর Work with Local Repo চাপুন। এখানেই সব content edit করবেন।

    http://localhost:8000/admin/

কাজ শুরু করার আগে

  • দুটি Terminal window চালু আছে
  • Address-এ localhost:8000/admin/ লেখা আছে
  • Work with Local Repo button চাপা হয়েছে
  • সাইটের সব ৯টি section editor-এ দেখা যাচ্ছে

Online mode চালু না করা পর্যন্ত live /admin/ page শুধু এই নির্দেশনাই দেখায়, আর editor খুলবে localhost ঠিকানা থেকে। চালু করার নিয়ম নিচে দেওয়া আছে।

Online mode · একবারের সেটআপ

ব্রাউজার থেকেই লেখা বদলাতে চাইলে।

GitHub-এ login করে সরাসরি live সাইট সম্পাদনা করতে একটি জিনিস দরকার: নিজের একটি OAuth client। এর গোপন key কখনোই public repository-তে রাখা যায় না, তাই সেটি থাকে একটি ছোট Cloudflare Worker-এ — free plan-এই যথেষ্ট। কাজটি একবারই করতে হবে।

  1. 1

    GitHub-এ একটি OAuth App বানান

    github.com/settings/developers খুলে OAuth Apps → New OAuth App চাপুন। নাম যা খুশি দিতে পারেন; Homepage URL-এ সাইটের ঠিকানা দিন। Callback URL এখন যা-ই থাকুক, ২ নম্বর ধাপের পরে সেটি বদলাতে হবে।

    https://tusher984.github.io/Tusher-Portfolio/

    App তৈরি হলে Client ID-টি কোথাও লিখে রাখুন, তারপর Generate a new client secret চেপে secret-টিও copy করে রাখুন — secret একবারই দেখানো হয়।

  2. 2

    একটি Cloudflare Worker deploy করুন

    Cloudflare-এ free account খুলে sveltia/sveltia-cms-auth repo-র README অনুযায়ী worker-টি deploy করুন। এটি Decap CMS-এর সাথেই কাজ করে, আর এর একমাত্র কাজ GitHub-এর secret-টি নিজের কাছে রাখা।

    তারপর worker-এর settings-এ তিনটি environment variable যোগ করুন। secret-টির পাশে Encrypt চাপবেন, নইলে সেটি dashboard-এ খোলা অবস্থায় থেকে যায়।

    GITHUB_CLIENT_ID      = <আপনার Client ID>
GITHUB_CLIENT_SECRET  = <আপনার Client Secret>   ← Encrypt
ALLOWED_DOMAINS       = tusher984.github.io

    শেষের লাইনটিই নিরাপত্তার তালা: worker কেবল এই ঠিকানার page-কে token দেয়, অন্য কোনো সাইট চাইলেও পায় না।

    Deploy শেষ হলে worker-এর ঠিকানা পাবেন — https://sveltia-cms-auth.YOUR-SUBDOMAIN.workers.dev। এখন GitHub-এ ফিরে গিয়ে OAuth App-এর Authorization callback URL-এ ওই ঠিকানার শেষে /callback যোগ করে বসান।

  3. 3

    admin/config.yml-এ একটি লাইন

    ফাইলটির শুরুতেই base_url লাইনটি comment করা আছে। সামনের # চিহ্নটি তুলে দিয়ে নিজের worker-এর ঠিকানা বসান — শেষে /callback দেবেন না, ওটা শুধু GitHub-এর ঘরের জন্য।

      base_url: https://sveltia-cms-auth.YOUR-SUBDOMAIN.workers.dev

    তারপর নিচের publish command তিনটি চালান। এক মিনিট পরে live /admin/ খুললে Login with GitHub বোতামটি দেখা যাবে।

লাইনটি যতক্ষণ comment করা থাকবে ততক্ষণ কিছুই বদলাবে না — live /admin/ এই নির্দেশনাই দেখাবে আর local editing আগের মতোই চলবে। আর চালু করার পরেও repository-তে write access আছে এমন GitHub account ছাড়া কেউ কিছু সেভ করতে পারবে না।

সম্পাদনা শেষে

Local থেকে live site-এ প্রকাশ করুন।

নিচের তিনটি command শুধু local mode-এর জন্য। Editor-এর ওপরের ডানদিকের Published বোতাম local mode-এ পরিবর্তনগুলো আপনার computer-এর ফাইলেই সেভ করে, তাই public website বদলাতে সেগুলো Git দিয়ে পাঠাতে হয়। Online mode-এ এই ধাপটি লাগে না — সেভ করলেই সরাসরি GitHub-এ commit হয় এবং সাইট এক-দুই মিনিটের মধ্যে নিজে থেকেই নতুন হয়ে যায়।

01 · Check

কী বদলেছে দেখুন

Terminal-এ git status লিখে বদলানো ফাইলের তালিকা দেখুন।

02 · Commit

পরিবর্তন সংরক্ষণ করুন

একটি ছোট message দিয়ে পরিবর্তনগুলো Git history-তে রাখুন।

03 · Push

লাইভ করুন

GitHub Pages সাধারণত এক মিনিটের মধ্যে নতুন version প্রকাশ করে।

git add -A
git commit -m "Update portfolio"
git push

সহায়তা

কোনো সমস্যা হলে

“Work with Local Repo” দেখা যাচ্ছে না

প্রথম Terminal-এ npx decap-server চলতে আছে কি না দেখুন। তারপর browser refresh করুন।

Page খুলছে না

দ্বিতীয় Terminal-এ python3 -m http.server 8000 চলছে কি না দেখুন এবং address ঠিক আছে কি না দেখুন।

ছবি upload হচ্ছে না

Editor local mode-এ খোলা আছে কি না নিশ্চিত করুন। Live site-এর address থেকে ছবি upload করা যাবে না।

Live site-এ change নেই

git push চালানোর পরে প্রায় এক মিনিট অপেক্ষা করে live site refresh করুন।

“Login with GitHub” চেপে 404 আসছে

OAuth App-এর callback URL-এ worker-এর ঠিকানার শেষে /callback আছে কি না দেখুন, আর config.yml-এর base_url-এ যেন /callback না থাকে।

Online mode-এ ছবি upload হবে?

হবে। Browser থেকে দেওয়া ছবি পুরো আকারে জমা হয়, আর publish-এর সময় GitHub Actions ছোট copy-গুলো নিজেই বানিয়ে নেয়।
