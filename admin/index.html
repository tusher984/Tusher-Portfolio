The login helper isn't deployed yet

Everything else is built and working — this page just cannot sign you in from the web until one small piece is online.

If you clicked "Login with GitHub" and got DNS_PROBE_FINISHED_NXDOMAIN — that was this: admin/config.yml still holds the placeholder address YOUR-LOGIN-HELPER.workers.dev. No such site exists, so your browser had nowhere to go. Nothing is broken. The five steps below replace that placeholder with a real address.

Edit right now, without any of this

In Terminal, in your site folder, run npx decap-server, then python3 -m http.server 8000 in a second window, and open localhost:8000/admin/. The full dashboard opens with no login at all, saves straight to the files on your computer, and git push publishes. This is the fastest route and it works today.

Or turn on login from anywhere (about ten minutes, free)

  1. Make a GitHub OAuth app. github.com → your photo → Settings → Developer settings → OAuth Apps → New OAuth App. Homepage URL is https://tusher984.github.io/Tusher-Portfolio/. Leave the callback URL for step 3. Register, then generate a client secret and keep both values open in a tab.
  2. Deploy the helper. dash.cloudflare.com → sign up free → Workers & Pages → Create → Hello World → Deploy. Then edit the code, delete what is there, paste the whole of admin/login-helper.js from your site folder, Deploy. Copy the address it gives you.
  3. Finish the GitHub app. Set its Authorization callback URL to that worker address with /callback on the end. This is the step that goes wrong most often — it must match exactly.
  4. Give the worker the secrets. Worker → Settings → Variables and Secrets. Add GITHUB_CLIENT_ID and GITHUB_CLIENT_SECRET, encrypt the secret one, Deploy again.
  5. Point this page at it. In admin/config.yml change base_url: to the worker address, then commit and push. Reload this page and the login button will appear.

The same steps, with more explanation, are at the top of admin/login-helper.js. I had no internet access while building this, so treat the button names above as carefully written rather than checked — Cloudflare and GitHub redesign their settings pages often. The shape of the steps is right even if a label has moved.
