Open the dashboard locally

The editor runs on your own computer. There is no online login, token, or Netlify connection.

  1. 1
    Open Terminal in this project folder

    Use the folder containing index.html and admin.

    cd ~/Documents/GitHub/Tusher-Portfolio
  2. 2
    Start the local CMS

    Leave this Terminal window running.

    npx decap-server
  3. 3
    Open a second Terminal window

    Run the local website server and leave it running too.

    cd ~/Documents/GitHub/Tusher-Portfolio
python3 -m http.server 8000
  4. 4
    Open the local dashboard

    Then choose Work with Local Repo. Your edits save straight into this folder.

    http://localhost:8000/admin/

To publish: after editing, return to Terminal and run git add -A && git commit -m "Update portfolio" && git push. GitHub Pages updates in about a minute.
