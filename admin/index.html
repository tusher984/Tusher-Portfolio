Almost there — one thing left

This is your content dashboard: photos, videos, stories, your bio, experience, skills and every heading on the site. It just needs permission to sign you in.

Open admin/config.yml and replace this one line:

base_url: https://YOUR-LOGIN-HELPER.workers.dev

The code you need is already in this folder, in admin/login-helper.js, with the setup steps written at the top. It takes about ten minutes and costs nothing.

In a hurry? You can edit everything right now without any of that. In a terminal, in your site folder, run npx decap-server, then python3 -m http.server in a second terminal, and open localhost:8000/admin/. Your changes save straight to the files on your computer — then git push to publish. Full instructions are in README.md.
